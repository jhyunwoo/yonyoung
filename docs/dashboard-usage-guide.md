# 대시보드 사용 가이드 (처음 가입한 사용자용)

## 1. 시스템 한눈에 보기
- 이 시스템은 `기수별 운영`과 `전역 운영`으로 나뉩니다.
- `기수별 운영`: 특정 기수의 공지, 활동, 전시, 멤버 관리.
- `전역 운영`: 전체 공지, 전체 멤버, 링크트리, 후원사, 기수 설정.
- 화면에 보이는 메뉴와 버튼은 **역할(Role)** 과 **할당된 기수**에 따라 자동으로 달라집니다.

## 2. 처음 가입부터 사용까지 (온보딩)
1. `Google 로그인`으로 가입합니다.
2. 첫 로그인 후 `프로필 작성` 화면으로 이동합니다.
3. 아래 필수 정보를 입력합니다.
4. 저장하면 `승인 대기` 상태가 됩니다.
5. 운영진이 역할과 기수를 승인/할당하면 대시보드에 접근할 수 있습니다.
6. 승인 후 다시 로그인하면 `대시보드`로 진입합니다.

### 프로필 필수 입력 항목
- 성(`familyName`)
- 이름(`givenName`)
- 단과대학(`college`)
- 학과(`department`)
- 학번(`studentNumber`, 10자리 숫자)
- 전화번호(`phoneNumber`, `010-0000-0000` 형식)

## 3. 역할 체계
| 역할 | 코드 | 의미 |
| --- | --- | --- |
| 회장 | `president` | 최고 관리자 |
| 부회장 | `vice_president` | 상위 관리자 |
| 운영진 | `manager` | 실무 관리자 |
| 신입회원 | `new_member` | 일반 사용자 |
| 준회원 | `associate_member` | 일반 사용자 |
| 정회원 | `regular_member` | 일반 사용자 |
| 미승인 | `unverified` | 승인 전 사용자 |

## 5. 메뉴 이해하기

### 메인 영역
- `대시보드 홈`: 요약 정보와 빠른 이동.
- `프로필`: 내 정보 확인/수정.
- `로그아웃`: 세션 종료.

### 기수별 영역
- `공지`: 기수 공지 확인/작성.
- `활동`: 활동 기록 작성/수정.
- `전시`: 전시 정보 운영.
- `멤버`: 기수 구성원 확인.

### 설정(전역) 영역
- `전체 공지`: 전사 공지 관리.
- `링크트리`: 링크 카테고리/아이템 관리.
- `후원사`: 후원사 정보 관리.
- `전체 멤버`: 사용자/권한 관리.
- `기수 관리`: 기수 생성/수정/삭제 (회장 중심).

## 6. 처음 쓰는 사람을 위한 실사용 순서
1. 로그인 후 프로필을 정확히 입력합니다.
2. 승인 완료 전에는 `승인 대기` 안내를 확인합니다.
3. 승인 후 대시보드 홈에서 본인 역할에 맞는 메뉴를 확인합니다.
4. 일반 회원은 `공지 확인 → 활동 등록`부터 시작합니다.
5. 운영진은 `기수 공지/전시/후원사/링크트리`를 운영합니다.
6. 부회장/회장은 `전체 멤버/권한/기수`까지 관리합니다.

## 7. 자주 겪는 상황과 해결
- 로그인했는데 대시보드가 안 열림: 프로필 미완료 또는 미승인 상태일 가능성이 큽니다.
- 메뉴가 안 보임: 역할 권한 또는 기수 할당 범위 때문입니다.
- 수정 버튼이 안 보임: 해당 기능이 조회 전용 권한일 수 있습니다.
- 다른 기수 데이터가 안 보임: 본인에게 할당된 기수 범위만 접근 가능한 상태입니다.

## 8. 운영 관점 핵심 정리
- 권한은 `역할` + `기수 범위`로 결정됩니다.
- `미승인(unverified)`은 실질적으로 운영 기능을 사용할 수 없습니다.
- `전체 공지/기수 삭제/전시 삭제`는 특히 높은 권한이 필요합니다.
- 신규 사용자는 반드시 `프로필 작성 → 승인` 단계를 거쳐야 정상 활용이 가능합니다.
