# 대시보드 조회수 통계 API 문서

> 대시보드 그래프 및 지표 표시를 위해 오늘/이번 주의 조회수와 이전 기간 대비 비교 데이터를 제공하는 API 명세입니다.

---

## 기본 정보

| 항목         | 값                                |
| ------------ | --------------------------------- |
| Base URL     | `https://yonyoung.yonsei.ac.kr`   |
| 경로         | `/api/admin/page-views/dashboard` |
| 메서드       | `GET`                             |
| 인증         | **필요** (관리자 권한 쿠키 세션)  |
| Content-Type | `application/json`                |

---

## 응답 명세 (200 OK)

요청 성공 시 다음과 같은 구조의 통계 데이터를 반환합니다.

### 데이터 구조 (`data`)

| 필드명               | 타입     | 설명                                                 |
| -------------------- | -------- | ---------------------------------------------------- |
| `today`              | `object` | 오늘의 방문 통계                                     |
| `today.count`        | `number` | 오늘 총 방문 수 (KST 기준)                           |
| `today.prevCount`    | `number` | 어제 총 방문 수 (KST 기준)                           |
| `thisWeek`           | `object` | 이번 주의 방문 통계                                  |
| `thisWeek.count`     | `number` | 이번 주 총 방문 수 (월요일~현재, KST 기준)           |
| `thisWeek.prevCount` | `number` | 지난 주 총 방문 수 (지난 주 월요일~일요일, KST 기준) |
| `dailyTrend`         | `array`  | 최근 30일간의 일별 방문 추세                         |
| `dailyTrend[].date`  | `string` | 날짜 (YYYY-MM-DD, KST 기준)                          |
| `dailyTrend[].count` | `number` | 해당 날짜의 방문 수                                  |

### 응답 예시

```json
{
  "data": {
    "today": {
      "count": 150,
      "prevCount": 120
    },
    "thisWeek": {
      "count": 850,
      "prevCount": 780
    },
    "dailyTrend": [
      { "date": "2026-05-10", "count": 110 },
      { "date": "2026-05-11", "count": 130 },
      { "date": "2026-05-12", "count": 120 }
    ]
  }
}
```

## 에러 응답

| 코드               | 설명                                   |
| ------------------ | -------------------------------------- |
| `401 Unauthorized` | 세션이 유효하지 않거나 로그인이 필요함 |
| `403 Forbidden`    | 조회 권한이 없는 사용자                |

---

## 구현 상세 참고 (개발자용)

- **시간대 처리**: 모든 통계는 한국 시간(KST, UTC+9)을 기준으로 집계됩니다.
- **주간 기준**: 월요일을 주의 시작일로 간주합니다.
- **데이터 소스**: `page_views` 테이블의 원시 로그 데이터를 실시간으로 집계하여 반환합니다.
- **비교 로직**:
  - `today.prevCount`: 어제 00:00:00 ~ 23:59:59 (KST)
  - `thisWeek.prevCount`: 지난 주 월요일 00:00:00 ~ 지난 주 일요일 23:59:59 (KST)

# 기간별 방문 분석 API

> 통계 화면(`/dashboard/stats`)이 쓰는 API입니다. 원하는 기간의 추이, 직전 같은 길이 기간과의 비교, 페이지 종류·인기 콘텐츠, 요일 패턴, 유입 경로와 기기를 한 번에 돌려줍니다.

## 기본 정보

| 항목   | 값                                                    |
| ------ | ----------------------------------------------------- |
| 경로   | `/api/admin/page-views/analytics`                     |
| 메서드 | `GET`                                                 |
| 인증   | **필요** (미승인 사용자 외 모든 회원)                 |
| MCP    | `page_view_analytics` 도구로도 같은 쿼리를 쓸 수 있음 |

## 쿼리 파라미터

| 이름          | 형식                     | 기본값                                            | 설명                                  |
| ------------- | ------------------------ | ------------------------------------------------- | ------------------------------------- |
| `from`        | `YYYY-MM-DD` (KST)       | `to` 기준 최근 30일의 첫날                        | 시작일, 포함                          |
| `to`          | `YYYY-MM-DD` (KST)       | 오늘                                              | 종료일, 포함. 오늘 이후면 오늘로 맞춤 |
| `granularity` | `day` / `week` / `month` | 31일 이하 `day`, 183일 이하 `week`, 그 외 `month` | 집계 단위. 주는 월요일 시작           |

`from > to`이거나 기간이 731일을 넘거나 실제 날짜가 아니면 `400`입니다.

## 응답 (`data`)

| 필드                  | 설명                                                                                                 |
| --------------------- | ---------------------------------------------------------------------------------------------------- |
| `range`               | 해석된 기간과 집계 단위                                                                              |
| `previousRange`       | 직전 같은 길이 기간                                                                                  |
| `summary`             | 총 조회수, 이전 기간 총 조회수, 일평균, 최고 조회일, 진입 수, 이전 기간 진입 수                      |
| `trend[]`             | `{ bucket, views, prevViews }`. 빈 날짜는 0으로 채움. 이전 기간 i번째 날은 현재 i번째 날과 같은 버킷 |
| `byPageType[]`        | 페이지 종류별 조회수                                                                                 |
| `topActivities[]`     | 기간 내 조회수 상위 활동 10개 (삭제된 항목 제외)                                                     |
| `topExhibitions[]`    | 기간 내 조회수 상위 전시 10개 (삭제된 항목 제외)                                                     |
| `weekdays[]`          | 요일별 일평균 조회수. `weekday`는 월요일이 0                                                         |
| `referrers[]`         | 유입 경로별 진입 수. `direct`는 직접 접속, `other`는 상위 10개 밖이거나 형식이 틀린 값               |
| `devices[]`           | 기기(`mobile`/`tablet`/`desktop`)별 진입 수                                                          |
| `entriesTrackedSince` | 진입 데이터 수집 시작일. 없으면 `null`                                                               |

## 진입(entry) 수집

- 웹 트래커는 문서 로드 후 첫 페이지뷰에만 `entry: true`를 보냅니다. 같은 사이트 안에서 새로고침한 경우는 진입이 아닙니다.
- 외부에서 들어왔다면 `referrerHost`(호스트명만)를 함께 보냅니다. 서버는 앞의 `www.`, `m.`을 떼고 형식을 검사합니다.
- 기기는 서버가 `User-Agent` 헤더로 판별합니다. IP와 UA 원문은 저장하지 않습니다.
- `page_view_entries` 테이블에 KST 일 단위로 `referrer`, `device` 행을 하나씩 누적합니다. 그래서 진입 총수는 `device` 행 합계와 같습니다.
- 수집은 마이그레이션 `0014_page_view_entries`를 배포한 날부터 쌓입니다. 그 이전 기간의 진입 수는 0입니다.
